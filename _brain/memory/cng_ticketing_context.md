# CNG / Jamesons Context

The project is a fresh standalone PHP 8 + MySQL ticketing system at `C:\xampp\htdocs\cng-ticketing`. It runs locally under XAMPP and will deploy to cPanel. No Composer or framework is allowed. SMTP configuration is outside Git. During deployment, remind the user to populate `config/config.local.php` with SMTP details. The Jamesons logo will later be dropped into `assets/`.
