# CNG / Jamesons Context

The project is a fresh standalone PHP 8 + MySQL ticketing system at `C:\xampp\htdocs\cng-ticketing`. It runs locally under XAMPP and will deploy to cPanel. No Composer or framework is used. SMTP configuration is outside Git; during deployment, populate `config/config.local.php` directly and never commit it. The Jamesons logo is vendored at `assets/jamesons-logo.svg` and used alongside the existing Strata Staff logo.
