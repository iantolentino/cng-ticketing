# CNG / Jamesons Decisions

- RBAC: roles, permissions, role grants, and user overrides are database records.
- Default create access: Pod Leaders only; Team Leaders are view/comment only.
- Statuses: Open, In Progress, Pending, Closed.
- Deletion: Super Admin soft deletes; audit data remains.
- Notifications: SMTP on creation and workflow changes, never comment-only changes.
- Branding: CSS variables use the approved blue, green, background, border, ink, and muted values.
